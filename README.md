# أسود الطريق 2.0

نسخة جديدة ومنظمة من نظام أسود الطريق: لوحة إدارة منفصلة + بوابة كابتن، مع قاعدة بيانات PostgreSQL واحدة وربط مباشر بين الطلبات والحسابات والعمولات والمدفوعات.

## المزايا
- صفحات مستقلة داخل نفس الموقع: Dashboard، الكباتن، الطلبات، المدفوعات، التقارير، الإعدادات.
- بوابة كابتن مستقلة تعرض الرصيد والإنتاج والاستهلاك والعمولات والطلبات وبيانات الدفع.
- كل Order مرتبط بكابتن ويتم تسجيل ربحه واستهلاكه وعمولته في كشف الحساب.
- حركات الإنتاج والاستهلاك تعتمد على أسعار قابلة للتعديل.
- كشف حساب مبني من Ledger بدل تعديل الرصيد النهائي يدوياً.
- PostgreSQL مع فهارس على الحقول التشغيلية المهمة.
- جلسات دخول موقعة HttpOnly.
- واجهة عربية RTL ومتجاوبة للموبايل والكمبيوتر.
- Health endpoint على `/health` مناسب للمراقبة.

## المعادلات الافتراضية
الإعدادات الافتراضية:
- إنتاج الراكب = 5 JD
- استهلاك الراكب = 4.25 JD
- إنتاج Order = 1 JD
- استهلاك Order = 0 JD
- أرضية الجروب = 0.50 JD

يمكن تعديلها من `/admin/settings.html`.

الرصيد المحاسبي = مجموع الإنتاج + الإضافات − الاستهلاك − العمولات − الخصومات − المدفوعات.

> العمولة ليست نفس قيمة الحساب تلقائياً. يتم تسجيلها كعنصر مستقل ويمكن إدخالها لكل Order.

## تشغيل محلي
1. ثبّت Node.js 20+ وDocker.
2. انسخ `.env.example` إلى `.env` وعدّل `ADMIN_PASSWORD` و`SESSION_SECRET`.
3. شغّل PostgreSQL:
   ```bash
   docker compose up -d db
   ```
4. ثبّت الحزم:
   ```bash
   npm install
   ```
5. شغّل التطبيق:
   ```bash
   npm start
   ```
6. افتح `http://localhost:3000/login.html`.

## تشغيل كامل عبر Docker
```bash
docker compose up --build
```

## النشر على Render
الأفضل استخدام Web Service + PostgreSQL. ضع المتغيرات:
- `DATABASE_URL` = رابط PostgreSQL
- `DATABASE_SSL=true` إذا كانت قاعدة البيانات تتطلب SSL
- `ADMIN_PASSWORD` = كلمة سر الإدارة الجديدة
- `SESSION_SECRET` = قيمة عشوائية طويلة
- `NODE_ENV=production`
- `PORT` يتركه Render أو يضبط تلقائياً

Build command: `npm install`
Start command: `npm start`

## ملاحظات مهمة قبل الإنتاج
- غيّر كلمة سر الإدارة فوراً ولا تضعها داخل الكود.
- استخدم PostgreSQL دائم وليس تخزيناً محلياً داخل التطبيق.
- فعّل HTTPS في الاستضافة.
- أضف نسخاً احتياطية دورية لقاعدة البيانات.
- هذه نسخة أساس كاملة قابلة للتشغيل؛ يمكن بعد ذلك إضافة صلاحيات متعددة للمشرفين، تصدير Excel/PDF، إشعارات WhatsApp عبر مزود رسمي، وسجل تدقيق Audit Log.
